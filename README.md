# The Human Edge — conference website

Static site for The Human Edge, inaugural salon of Sustainable High Performance (10–11 December 2026, Sports Equity Lab, Stanford University, and online).

## Pages

- `index.html` — landing page and tickets
- `terms.html` — ticket terms, refunds and transfers
- `privacy.html`, `cookies.html`, `legal.html` — legal pages

## Payment links

Ticket buttons read their checkout URLs from `assets/config.js`. Paste the Luma or Stripe link for each pass between the quotes; an empty value keeps the button scrolling to the tickets section.

## Before launch

Fill the placeholders in square brackets on the legal pages: registered address, contact email, payment provider and VAT wording.

## Hosting

Served with GitHub Pages from the `main` branch root. A custom domain is set in the repository's Settings → Pages.
